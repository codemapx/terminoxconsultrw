# About Page Plan

## What will be built
- Add a dedicated `/about` page matching the existing TERMINO-X visual style.
- Tell the company story using only facts already established on the website: Kigali roots, practical business support, skills development, and the skills-to-income mission.
- Present the team through its real working functions—business growth, training, digital solutions, and the agent network—without inventing personal names or biographies.
- Add a milestone journey using truthful phases rather than fabricated dates.
- Reuse the project’s existing authentic business and training imagery with subtle reveal and hover animation.
- Add clear links back to services, programs, WhatsApp, and the homepage.

## Page structure
1. Photo-led introduction with the TERMINO-X name and purpose.
2. Origin story and mission.
3. Values and measurable focus areas.
4. Team functions and how they support clients.
5. Journey timeline: the need, the model, the programs, and today’s network.
6. Kigali call-to-action.

## Technical details
- Create `src/routes/about.tsx` with unique search and social metadata.
- Use TanStack Router links and the existing `Reveal` animation helper.
- Reuse semantic design tokens, existing image assets, and existing button components.
- Keep the page responsive and reduced-motion friendly.
- Verify `/about` at desktop and mobile sizes and check for browser errors.
